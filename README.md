## 🌟 Ключевые возможности

- 📚 **Обширный каталог (1822+ проекта):**
  - Поддержка четырёх категорий: **Моды**, **Сборки (Модпаки)**, **Шейдеры** и **Ресурспаки**.
  - Данные собраны из крупнейших репозиториев **Modrinth** и **CurseForge**.
  - Быстрый поиск по названию и описанию, мгновенная пагинация без подвисаний.

- 🇷🇺 **Полная русская локализация (RU | EN):**
  - Все описания и названия проектов переведены на русский язык.
  - Мгновенное переключение языка интерфейса и карточек в шапке программы.

- 🧩 **Автоматическая установка зависимостей:**
  - При установке модов программа сама определяет требуемые библиотеки (например, *Fabric API*, *Cloth Config*, *Architecture API*, *Oculus*, *Iris* и др.) и скачивает их в нужную папку в фоновом режиме.

- ⚡ **Надёжная загрузка с отменой на лету:**
  - Потоковое скачивание файлов чанками с отображением реального процента прогресса прямо на карточке и в окне мода.
  - Интерактивная кнопка отмены: прерывает загрузку, корректно закрывает соединение и удаляет временные `.part` файлы с диска.

- 📂 **Умное управление папками Minecraft:**
  - Автоматическое разделение контента по директориям: моды в `mods/`, шейдеры в `shaderpacks/`, ресурспаки в `resourcepacks/`.
  - Возможность **закрепить папку** (кнопка 📌 «Закрепить» сохраняет путь в `config.json` между перезапусками).
  - Быстрый переход в проводнике Windows: кнопка «📂 Показать в папке» напротив каждого установленного файла.
  - Совместимость с любыми лаунчерами: **Prism Launcher**, **Modrinth App**, **CurseForge**, **TLauncher**, официальный лаунчер Minecraft.

- 🛠 **Встроенный Конструктор сборок:**
  - Добавляйте понравившиеся моды в конструктор в один клик и экспортируйте готовую сборку в `.zip` архив.

- 📖 **Интерактивная инструкция:**
  - Пошаговые иллюстрированные руководства по правильной установке ядер (Fabric, Forge, NeoForge), модов, шейдеров и импорту сборок.

- 🎨 **Современный Pulse Dark UI:**
  - Плавные аппаратные анимации, неоновый тёмный стиль, отсутствие мерцания и микрофризов при переключении категорий.

## 🚀 Скачивание и запуск готовой версии (Релиз)

Самый простой способ — использовать готовую портативную версию для Windows, не требующую установки Python или компиляторов:

1. Перейдите на страницу **[Releases](https://github.com/...)** репозитория.
2. Скачайте архив свежего релиза: `ModCraftAssistant-v1.0.0-windows.zip`.
3. Распакуйте архив в удобное место на компьютере.
4. Запустите **`ModCraftAssistant.exe`**.

> [!NOTE]
> База данных `mods.db` (объём ~213 МБ с 1822 проектами и переводами) уже включена в архив релиза. В репозитории GitHub она не хранится из-за лимита GitHub на одиночные файлы в 100 МБ.

## 💻 Запуск из исходного кода (для разработчиков)

Если вы хотите запустить проект напрямую из исходников или внести изменения:

### 1. Клонирование репозитория

```bash
git clone https://github.com/YOUR_USERNAME/ModCraftAssistant.git
cd ModCraftAssistant
```

### 2. Настройка виртуального окружения

```bash
# Windows
python -m venv .venv
.venv\Scripts\activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Подготовка базы данных `mods.db`

Поскольку файл `mods.db` весит более 100 МБ, скачайте его из архива последнего релиза в разделе **Releases** и поместите в корень проекта рядом с `app.py`.

### 5. Запуск приложения

```bash
python app.py
```

## 📦 Сборка собственного исполняемого файла (.exe)

Для сборки портативной версии `--onedir` используется настроенный скрипт:

```bash
python scripts/build_release.py
```

Скрипт автоматически:
1. Запустит PyInstaller со спецификацией `ModCraftAssistant.spec` (оконный режим без чёрной консоли, с иконкой `assets/icon.ico`).
2. Скопирует свежие ресурсы `web/`, `assets/` и базу данных `mods.db` в папку `dist/ModCraftAssistant/`.
3. Проведёт тест целостности созданного дистрибутива.

Итоговый билд будет находиться в директории:
```
dist/ModCraftAssistant/
├── ModCraftAssistant.exe
├── mods.db
├── web/
├── assets/
└── _internal/
```

## 📂 Структура проекта

```
├── app.py                      # Точка входа в приложение (запуск pywebview)
├── ModCraftAssistant.spec      # Конфигурация сборки PyInstaller
├── requirements.txt            # Список зависимостей Python
├── README.md                   # Документация проекта
├── .gitignore                  # Исключения для Git
│
├── backend/                    # Python бэкенд
│   ├── api.py                  # API-контроллер для JS (поиск, скачивание, отмена, фильтры)
│   └── catalog_sync.py         # Модуль фоновой синхронизации каталога
│
├── web/                        # Фронтенд интерфейс (HTML5 / CSS3 / Vanilla JS)
│   ├── index.html              # Разметка каталога, модальных окон и конструктора
│   ├── style.css               # Тёмная тема Pulse UI, сетка карточек, анимации
│   └── app.js                  # Логика взаимодействия с API, мультиязычность, кэш
│
├── database/                   # Модели и схема базы данных SQLite
│   ├── models.py               # Описание таблиц mods и mod_files
│   └── engine.py               # Подключение к БД
│
├── assets/                     # Статические ресурсы (иконка icon.ico и логотипы)
│
└── scripts/                    # Скрипты автоматизации и сборки
    ├── build_release.py        # Финальная сборка релиза
    └── translate_missing.py    # Пакетный перевод описаний через deep-translator
```

## 🛠 Технологический стек

- **Язык:** Python 3.10+
- **Оконный движок:** [pywebview](https://pywebview.flowrl.com/) + Microsoft Edge WebView2
- **База данных:** SQLite 3 (оптимизированные индексы, подзапросы, транзакции)
- **Фронтенд:** Vanilla JavaScript (ES6+), Modern CSS (Flexbox, Grid, CSS Variables), HTML5
- **Сеть:** Requests (потоковая загрузка чанками по 16 КБ, поддержка отмены)
- **Сборщик:** PyInstaller 6.x
